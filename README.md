# OverTime Control

**Sistema web para la gestión y control de horas extras del personal en organizaciones.**

## Descripción

OverTime Control es un sistema orientado a facilitar la gestión, validación y seguimiento de las horas extras de los empleados, mediante la integración con sistemas biométricos y procesos de aprobación.

## Tecnologías

- **Frontend:** React.
- **Backend:** Java y Spring Boot.
- **Base de datos:** PostgreSQL.
- **Mensajería asíncrona:** RabbitMQ.
- **Autenticación:** Keycloak.
